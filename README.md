# DTO (Distributed Test Orchestrator)

DTO — это высокопроизводительная распределенная система для нагрузочного тестирования REST API, написанная на Go. 

Инструмент позволяет генерировать огромный объем HTTP-трафика с минимальным потреблением системных ресурсов благодаря использованию библиотеки `fasthttp`. DTO поддерживает как локальный запуск (Solo Mode), так и распределенный (Distributed Mode) с использованием gRPC-агентов.

## 🚀 Ключевые возможности

- **Высокая производительность:** Способность генерировать десятки тысяч RPS при минимальном потреблении RAM и CPU.
- **Распределенный режим:** Масштабирование нагрузки с помощью подключаемых агентов.
- **Интеграция с Prometheus & Grafana:** Экспорт метрик в реальном времени (RPS, Latency, распределение статусов, сетевые ошибки).
- **Гибкая конфигурация:** Описание сценариев тестирования в удобном YAML-формате.

## 📦 Установка

### Локальная установка через `go install`
Убедитесь, что у вас установлен Go (1.22+). Выполните команду:

```bash
go install https://github.com/tendze/diplom2026_distributed_test_orchestrator/cmd/dtoctl@latest
```

Убедитесь, что ваш $GOPATH/bin добавлен в переменную окружения PATH

## 🚦 Использование

1. Настройка сценария
Создайте файл конфигурации test-scenario-example.yaml (пример есть в корне репозитория):
2. Для соло запуска (прямо с вашего компьютера) нужно не указывать поле agents:
```bash
dtoctl run-test <путь к .yml сценарию>
```
3. Распределенный режим с агентами:
Сначала запустите агентов на целевых машинах (или локально для теста):
```bash
dtoctl start agent --listen :9001
```

Затем запустите контроллер, передав ему сценарий, предварительно заполнив поле agents:
```bash 
dtoctl run-test <путь к .yml сценарию>
```

## 🛠 Запуск инфраструктуры мониторинга

Для визуализации метрик в реальном времени системе требуются Prometheus и Grafana. Готовые конфигурации лежат в директории ```deploy/```. Скопируйте их в отдельную директорию, перейдите туда и запустите контейнеры с помощью команды:
```bash 
docker-compose up -d
```

Grafana будет доступна по адресу http://localhost:3000

В Data Source выберите Prometheus, введите адрес http://localhost:9090/metrics и затем импортируйте ```dashboard.json``` из ```/deploy```
